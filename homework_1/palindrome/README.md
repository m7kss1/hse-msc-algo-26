# Задача 1. Палиндром

Проверить, является ли целое положительное число палиндромом

## Идея

Разворачиваем число арифметикой:

* `n % 10` - последняя цифра,
* `rev = rev * 10 + цифра` - приклеиваем её к развернутому числу,
* `n //= 10` - укорачиваем исходное

Когда цифры кончились, сравниваем развернутое число с исходным: равны, значит палиндром

## Сложность

* **Время O(log n)**: один проход по цифрам, их `log10(n) + 1`
* **Память O(1)**

## Как это работает по шагам

Слева отгрызаем цифры, справа собираем перевёрнутое число (`make demo`)

```
 шаг | цифра | x (остаток) |      rev
----------------------------------------
   0 |     - |       12321 |        0
   1 |     1 |        1232 |        1
   2 |     2 |         123 |       12
   3 |     3 |          12 |      123
   4 |     2 |           1 |     1232
   5 |     1 |           0 |    12321

rev = 12321, n = 12321  ->  True
```
