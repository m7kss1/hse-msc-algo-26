# Задача 2. Сумма

На вход подаётся массив целых чисел через пробел. Найти максимальную сумму элементов массива, которая делится на 2

Решение сделано для **общего случая**: числа могут быть любого знака

## Идея

**Шаг 1. Что берем вообще.** Отрицательное число только уменьшает сумму, ноль ничего не меняет, значит берем все положительные. Их сумма - это верхняя граница ответа

**Шаг 2. Чиним четность.** Если сумма четная, это и есть ответ. Если нечетная, менять четность умеет только нечетное число и вариантов два:

* **выбросить** положительное нечетное, дешевле всего выбросить самое маленькое;
* **добавить** отрицательное нечетное, дешевле всего взять ближайшее к нулю.

Берем тот, что дешевле. Если сумма нечетная, положительное нечетное число точно есть, отрицательных нечетных может не быть

## Сложность

* **Время O(n)**: несколько проходов по массиву
* **Память O(1)**

## Как это работает по шагам

Пример `5 7 13 2 14 -1 -8` - здесь доступны оба варианта починки четности, и выгоднее оказывается второй (`make demo`)

```
числа:               [5, 7, 13, 2, 14, -1, -8]
берём положительные: [5, 7, 13, 2, 14]
их сумма:            41  - нечетная

A) выбросить наименьшее положительное нечётное 5: 41 - 5 = 36
B) добавить ближайшее к нулю отрицательное нечётное -1: 41 + (-1) = 40

ответ: 40
```

## Запуск и тестирование

```bash
make test                       # прогнать тесты, ненулевой код возврата при падении
make run ARGS="5 7 13 2 14"     # решение на своём вводе
echo "5 7 13 2 14" | make run   # то же через stdin
make examples                   # примеры из условия
make demo                       # пошаговая визуализация
make help                       # список команд
```
