# Задача 2. Iterative

## Идея

**Mergesort** строится снизу вверх. Сначала каждый элемент сам по себе отсортирован, поэтому сливаем соседние отрезки длины 1. Затем сливаем соседние отсортированные отрезки длины 2, 4 и так далее. Если в конце остался короткий отрезок без пары, он копируется как есть. После прохода длина отсортированных отрезков удваивается, пока не покроет весь массив

Для слияния используем второй массив той же длины. На проходе читаем из одного массива, записываем в другой, а после прохода меняем их местами. При равенстве первым берем элемент слева, поэтому порядок равных элементов сохраняется

**Quicksort** вместо рекурсивных вызовов хранит на стеке границы подмассивов. Извлекаем диапазон, берем его последний элемент как опорный и за один проход разбиваем на меньшие, равные и большие. Равные уже стоят на своих местах, на стек кладем только диапазоны меньших и больших. Больший кладем первым, чтобы меньший обработался раньше и стек не разрастался

Обе функции возвращают новый массив, входной не меняется

## Сложность

`n` это длина массива

* **Mergesort: время O(n log n)**: O(log n) проходов по n элементам. Память O(n) на копию и буфер
* **Quicksort: время O(n log n)** при сбалансированных разбиениях, **O(n^2)** в худшем случае при сильно неравных разбиениях. На одинаковых элементах достаточно одного прохода, O(n)
* **Quicksort: память O(n)** на копию и O(log n) на стек: пока отложен больший диапазон, обрабатываем меньший, его размер не больше половины исходного. Само разбиение выполняется внутри копии

## Как это работает по шагам

Пример `[4,1,3,2,3]` (`make demo`):

```
mergesort, длина сливаемых отрезков:
  1: [1,4,2,3,3]   слили [4] с [1], [3] с [2], [3] остался
  2: [1,2,3,4,3]   слили [1,4] с [2,3]
  4: [1,2,3,3,4]   слили [1,2,3,4] с [3]

quicksort, диапазон и опорный:
  [0,4], 3: [1,2,3,3,4], равные [2,3]
  [0,1], 2: [1,2,3,3,4], равные [1,1]
```

После первого разбиения элементы с индексами 2 и 3 равны опорному, слева только меньшие, справа только большие. Справа один элемент, поэтому на стек остается положить только `[0,1]`
