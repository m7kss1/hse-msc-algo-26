# Задача 3. K-th

## Идея

Нужен `k`-й по величине элемент с учетом повторов. В порядке возрастания его индекс равен `n - k`: например, второй по величине находится на предпоследней позиции. Сортировать весь массив не нужно, достаточно найти элемент на этом индексе

Quickselect работает с одним диапазоном. Берем средний по индексу элемент как опорный и разбиваем диапазон на три части: меньше, равные и больше него. Границы блока равных обозначим `low` и `high`

* искомый индекс меньше `low`, продолжаем слева
* индекс больше `high`, продолжаем справа
* индекс внутри блока равных, ответ найден

После разбиения все элементы слева меньше опорного, все справа больше, поэтому блок равных уже занимает те же позиции, что занимал бы в отсортированном массиве. Выбранная сторона содержит искомую позицию, вторую сторону больше не рассматриваем. На каждом шаге диапазон уменьшается хотя бы на блок равных

Разбиение переставляет элементы, поэтому сначала делаем копию. Исходный массив не меняется. При пустом массиве или `k` вне диапазона от 1 до n функция вызывает `ValueError`

## Сложность

`n` это длина массива

* **Время O(n)** в среднем при достаточно удачных разбиениях: обрабатываем все меньшие диапазоны, их суммарная длина порядка n. **O(n^2)** в худшем случае, когда каждый раз исключается только один элемент. Выбор опорного по среднему индексу не гарантирует сбалансированных разбиений для любого входа
* **Память O(n)** на копию массива, само разбиение и итеративный поиск используют O(1) дополнительной памяти

## Как это работает по шагам

Пример из условия (`make demo`), ищем четвертый по величине, индекс по возрастанию `9 - 4 = 5`

```
nums = [3, 2, 3, 1, 2, 4, 5, 5, 6], k = 4

шаг | диапазон | опорный | после разбиения             | равные | куда
  1 | [0,8]    | 2       | [1,2,2,3,4,5,5,6,3]        | [1,2]  | вправо
  2 | [3,8]    | 5       | [1,2,2,3,4,3,5,5,6]        | [6,7]  | влево
  3 | [3,5]    | 4       | [1,2,2,3,3,4,5,5,6]        | [5,5]  | найдено

ответ: 4
```

После первого шага индекс 5 правее блока равных двойке, на втором шаге левее блока равных пятерке, на третьем попадает в блок четверок. Повторяющиеся значения считаются отдельными элементами массива

## Запуск и тестирование

```bash
make test                                  # примеры, границы и случайные массивы

make demo                                  # пошаговая визуализация
```
