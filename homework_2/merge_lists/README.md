# Задача 3. Merge lists

Даны два отсортированных односвязных списка. Объединить их в один отсортированный, составив его из узлов исходных списков, и вернуть голову результата

## Идея

Обычное слияние, как в merge sort. Держим указатели на головы обоих списков и на хвост результата. На каждом шаге сравниваем два текущих значения, меньшее прицепляем к хвосту результата и сдвигаем указатель того списка, откуда взяли. Как только один список кончился, второй прицепляем целиком - он уже отсортирован, сравнивать больше не с чем

Новые узлы не создаем, переставляем ссылки `next` у существующих. Поэтому после слияния исходные списки использовать нельзя: их узлы уехали в новый

Реализовано двумя способами:

* **С фиктивным узлом** (`merge_with_dummy`). Заводим пустой узел `dummy` и начинаем строить результат от него. Тогда у хвоста всегда есть куда писать, и первый шаг ничем не отличается от остальных. В конце возвращаем `dummy.next`, сам фиктивный узел выбрасываем
* **Без фиктивного узла** (`merge_without_dummy`). Первый шаг делаем руками: голову результата выбираем как меньшую из двух голов (плюс отдельно разбираем случай, когда один из списков пуст). Дальше тот же цикл. Кода больше, зато не создаем лишний узел

Равные значения берем из `list1` (сравнение `<=`), поэтому слияние устойчивое: узлы с одинаковыми значениями сохраняют относительный порядок

## Сложность

Для списков длины `n` и `m`:

* **Время O(n + m)**: каждый узел попадает в результат ровно один раз, сравнений не больше `n + m`
* **Память O(1)** дополнительной: только указатели, узлы переиспользуются. Фиктивный узел - ещё одна константа\

## Как это работает по шагам


```
 шаг | сравнение    | берем   | результат                | остаток list1   | остаток list2
--------------------------------------------------------------------------------------------
   0 | -            | -       | []                       | [1, 2, 4, 8]    | [1, 3, 4]
   1 | 1 <= 1       | list1   | [1]                      | [2, 4, 8]       | [1, 3, 4]
   2 | 1 <  2       | list2   | [1, 1]                   | [2, 4, 8]       | [3, 4]
   3 | 2 <= 3       | list1   | [1, 1, 2]                | [4, 8]          | [3, 4]
   4 | 3 <  4       | list2   | [1, 1, 2, 3]             | [4, 8]          | [4]
   5 | 4 <= 4       | list1   | [1, 1, 2, 3, 4]          | [8]             | [4]
   6 | 4 <  8       | list2   | [1, 1, 2, 3, 4, 4]       | [8]             | []
   7 | один пуст    | list1   | [1, 1, 2, 3, 4, 4, 8]    | []              | []

ответ: [1, 1, 2, 3, 4, 4, 8]
```

## Запуск и тестирование

```bash
make test                            # прогнать тесты, ненулевой код возврата при падении
make run ARGS="1 2 4 / 1 3 4"        # решение на своём вводе, списки через /
printf "1 2 4\n1 3 4\n" | make run   # то же через stdin, двумя строками
```
