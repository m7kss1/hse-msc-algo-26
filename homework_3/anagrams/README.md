# Задача 2. Anagrams

Дан список слов. Сгруппировать слова так, чтобы в одной группе оказались все анаграммы

## Идея

Два слова - анаграммы, если состоят из одних и тех же букв в одинаковом количестве. Сравнивать каждое слово с каждым - это O(n^2) сравнений. Вместо этого сопоставим каждому слову **подпись**, одинаковую у анаграмм и разную у всех остальных, и разложим слова по подписям через хеш-таблицу

Подпись - буквы слова, отсортированные по порядку: `eat`, `tea`, `ate` -> `aet`. Отсортированная строка однозначно задает набор букв с кратностями, поэтому подписи совпадают ровно у анаграмм

Дальше один проход: словарь `подпись -> список слов`, каждое слово дописываем в список своей подписи (`setdefault` заводит пустой список, если подпись встретилась впервые). Список групп - это значения словаря

Альтернатива для алфавита `a-z` - подпись из 26 счетчиков букв, она строится за O(L) вместо O(L log L). Но она привязана к алфавиту, а сортировка работает для любых символов, поэтому выбрана она

## Сложность

`n` слов, длина слова не больше `L`:

* **Время O(n L log L)**: подпись каждого слова - сортировка его букв, операции со словарем O(L) в среднем (хеш строки длины L). Приведение к виду из примера для вывода добавляет сортировку слов и групп, O(n log n L)
* **Память O(n L)**: подписи и списки групп хранят все слова

## Как это работает по шагам

Пример из условия (`make demo`)

```
strs = ['eat', 'tea', 'tan', 'ate', 'nat', 'bat']

 шаг | слово    | подпись  | группа после шага
------------------------------------------------------
   1 | eat      | aet      | новая: [eat]
   2 | tea      | aet      | [eat, tea]
   3 | tan      | ant      | новая: [tan]
   4 | ate      | aet      | [eat, tea, ate]
   5 | nat      | ant      | [tan, nat]
   6 | bat      | abt      | новая: [bat]

группы:
  aet      -> ['eat', 'tea', 'ate']
  ant      -> ['tan', 'nat']
  abt      -> ['bat']

ответ: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

## Запуск и тестирование

```bash
make test                                # прогнать тесты, ненулевой код возврата при падении
make run ARGS="eat tea tan ate nat bat"  # решение на своём вводе, слова через пробел
echo "eat tea tan" | make run            # то же через stdin
make examples                            # пример из условия
make demo                                # пошаговая визуализация
make help                                # список команд
```
