# Задача 2. Validate BST

## Идея

Дерево - BST, если у **каждого** узла все значения в левом поддереве строго меньше его, а в правом строго больше. Повторы поэтому запрещены: `[2,2,2]` и `[2,null,2]` - не BST

Сравнить узел только с детьми мало. Ниже у каждого узла дети в порядке, но `9` лежит в левом поддереве `8`, а должно быть меньше `8`:

```
      ___8_
     /     \
     3_   10_
    /  \     \
    1  6    14
      / \
      4 9
```

Ограничение на узел приходит от всех предков: каждый, от которого ушли влево, задает верхнюю границу, а от которого ушли вправо - нижнюю. Хватает самых жестких, поэтому у узла есть интервал `(low, high)`:

* у корня `(-inf, +inf)`
* левый ребенок узла `v` получает `(low, v)`, правый - `(v, high)`

Если все узлы внутри своих интервалов, то любой узел левого поддерева `v` меньше `v` (границы при спуске только сужаются), и симметрично справа. Если какой-то узел вылетел, нарушено сравнение с предком, который задал эту границу

Обходим дерево своим стеком из троек `(узел, low, high)`, без рекурсии: у дерева-цепочки глубина равна числу узлов. На первом узле вне интервала возвращаем `False`. Отсутствие границы - это `None`, а не `INT_MIN/INT_MAX`, поэтому крайние значения не ломают проверку

Дерево подается по уровням, как на LeetCode: `5 1 4 null null 3 6` или `[5,1,4,null,null,3,6]`. Пустое дерево - BST

## Сложность

`n` узлов, `h` - высота дерева

* **Время O(n)**: каждый узел один раз кладется на стек и проверяется двумя сравнениями
* **Память O(h)**: снимая узел, кладем не больше двух детей, левого сверху, поэтому на каждом уровне ждет не больше одного правого брата. Для сбалансированного дерева O(log n), для цепочки O(n)

## Как это работает по шагам

```
      ___8_
     /     \
     3_   10_
    /  \     \
    1  6    14
      / \
      4 9

 шаг |   узел | допустимо        | проверка | стек (дно -> вершина)
-----------------------------------------------------------------------------
   1 |      8 | (-inf, +inf)     | ok       | 10(8, +inf) 3(-inf, 8)
   2 |      3 | (-inf, 8)        | ok       | 10(8, +inf) 6(3, 8) 1(-inf, 3)
   3 |      1 | (-inf, 3)        | ok       | 10(8, +inf) 6(3, 8)
   4 |      6 | (3, 8)           | ok       | 10(8, +inf) 9(6, 8) 4(3, 6)
   5 |      4 | (3, 6)           | ok       | 10(8, +inf) 9(6, 8)
   6 |      9 | (6, 8)           | НАРУШЕНО | 10(8, +inf)

9 не лежит в (6, 8)  ->  False
```

Граница `8` у узла `9` пришла не от родителя `6`, а от корня: на шаге 1 ушли от `8` влево, и интервал `(-inf, 8)` унаследовало все левое поддерево. Правое поддерево `10` проверять уже не пришлось

## Запуск и тестирование

```bash
make test                                   # прогнать тесты, ненулевой код возврата при падении
make run ARGS="'[5,1,4,null,null,3,6]'"     # решение на своём вводе, дерево по уровням
make run ARGS="2 1 3"                       # то же без скобок и запятых
echo "2 1 3" | make run                     # то же через stdin
```
